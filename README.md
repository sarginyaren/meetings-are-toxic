# Meetings Are Toxic

A 5-slide, 5-minute talk on **Chapter 38 of [Getting Real](https://basecamp.com/gettingreal)** by Basecamp.

**Live slides:** https://sarginyaren.github.io/meetings-are-toxic/
(enable GitHub Pages: Settings → Pages → Deploy from branch → `main` / root)

## Controls

| Key | Action |
| --- | --- |
| `→` / `Space` / click | Next slide |
| `←` | Previous slide |
| `N` | Show / hide the speaker script |
| `F` | Fullscreen |
| `Home` / `End` | First / last slide |

On a phone the slide sits at the top and the speaker script below it. Swipe left/right on the slide to change slides.
Each slide has a URL (`#1` … `#5`), and `Ctrl/Cmd + P` prints the deck as a PDF.

## Outline

1. Meetings Are Toxic
2. The core question: do you really need this meeting?
3. Seven reasons meetings hurt, plus the n(n−1)/2 math
4. If you must meet: three rules
5. The big idea + starting tomorrow + Q&A

Single self-contained `index.html`, no build step.
